# Tableau 대시보드 제작 가이드

Tableau Desktop 2026.2 기준입니다. 데이터는 `data/tableau/`의 CSV 4개를 씁니다. 모두 공개 가능한 집계값입니다.

- 대시보드 크기: **고정 1200 × 1000** (Tableau Public 화면에 맞는 폭)
- 글꼴: 기본(Tableau Book). 한글은 Tableau Public에서 자동 대체 글꼴로 표시됩니다.
- 색: 한국투자증권 **#E8541F**(주황), 미래에셋증권 #4C78A8, 삼성증권 #72B7B2, 기타 증권사 #C9CED6(회색). 히트맵은 회색에서 주황으로 가는 순차 색상.

## 빠른 시작: 미리 만든 통합문서로 시작하기

`data/tableau/irp_aov_radar.twb`를 열면 데이터 연결과 시트 4개(차트 종류·필드 배치·정렬)가 이미 들어 있습니다. `python scripts/build_twb.py`로 다시 만들 수 있습니다. 열고 나서 아래만 마무리하면 됩니다.

| 시트 | 남은 작업 (끌어다 놓기) |
|---|---|
| 1 객단가 격차 | 색상 범례에서 한국투자증권을 주황(#E8541F)으로, 세로축에 참조선(상수 1,858, 레이블 "전 업권 평균 1,858만 원") |
| 2 불편 히트맵 | `company`를 필터로 끌고 **필터 표시**, 색상을 회색→주황 순차 색상으로 |
| 3 기회 | 레이블 `share_3co`를 백분율 서식으로, 도구 설명 문구 정리 |
| 4 관리 | 열 너비 조정 |

그다음 아래 **대시보드 조립**과 **Tableau Public에 저장**으로 넘어갑니다.

- 파일을 열 때 데이터 파일을 찾지 못한다는 창이 뜨면, `data/tableau` 폴더의 같은 이름 CSV를 지정하면 됩니다.
- 시트의 행 이름 앞 번호("1. 가입·계좌개설")는 순서를 고정하기 위한 것입니다.

## 0. 데이터 연결 (처음부터 만들 때)

1. **데이터 > 새 데이터 원본 > 텍스트 파일**에서 `t1_aov_trend.csv`를 엽니다.
2. 같은 방법으로 `t2_heatmap.csv`, `t3_opportunities.csv`, `t4_quality.csv`를 각각 **별도 데이터 원본**으로 추가합니다(조인하지 않음).
3. 각 원본에서 `year`, `stage_order`, `pain_order`는 **차원**으로 바꿉니다(필드 우클릭 > 차원으로 변환). `year`는 불연속으로 둡니다.

## 화면 1. 객단가 격차 — "방문자는 1위, 객단가는 아래"

시트 이름: `1 객단가 격차` / 원본: `t1_aov_trend`

| 항목 | 설정 |
|---|---|
| 필터 | `year` = 2025 |
| 열 | `SUM(contracts)` — 축 제목 "IRP 계약 수(건)" |
| 행 | `SUM(reserve_per_contract_10k_krw)` — 축 제목 "계약 1건당 적립금(만 원)" |
| 마크 | 원 |
| 크기 | `SUM(reserve_100m_krw)` |
| 색상 | `highlight` (위 색 지정) |
| 레이블 | `provider` (한국투자·미래에셋·삼성만 표시: 레이블 > 선택한 항목 또는 강조) |
| 참조선 | 행 축에 `AVG(market_avg_per_contract_10k_krw)` 상수 참조선, 레이블 "전 업권 평균 1,858만 원", 점선 |
| 도구 설명 | `<provider>` 계약 `<SUM(contracts)>`건 · 1건당 `<SUM(reserve_per_contract_10k_krw)>`만 원 |

주석(시트 위 텍스트 박스): **"한국투자증권: 계약 수 1위, 1건당 적립금 1,572만 원 (미래에셋의 42%, 전 업권 평균보다 낮음)"**

보조 시트 `1b 추이` (선택): 필터 `highlight` ≠ 기타 증권사, 열 `year`, 행 `SUM(reserve_per_contract_10k_krw)`, 색상 `highlight`, 마크 선. 2017~2025년 1건당 적립금이 어떻게 벌어졌는지 보여 줍니다.

## 화면 2. 불편 히트맵 — "어느 단계에서, 무엇 때문에"

시트 이름: `2 불편 히트맵` / 원본: `t2_heatmap`

| 항목 | 설정 |
|---|---|
| 열 | `pain_type` — 정렬: 필드 `pain_order` 최솟값 오름차순 |
| 행 | `journey_stage` — 정렬: 필드 `stage_order` 최솟값 오름차순 |
| 마크 | 사각형 |
| 색상 | `SUM(reviews)` (회색 → 주황) |
| 레이블 | `SUM(reviews)` |
| 필터 | `company` — **필터 표시**, 단일 값(드롭다운) + "(모두)" 허용, 기본값 "(모두)" |
| 도구 설명 | `<journey_stage>` × `<pain_type>`: `<SUM(reviews)>`건 |

주석: **"불편 264건 중 59%가 가입 이후(수익률·잔고 조회, 상품 선택·운용)에 몰림"**
캡션: "한국투자증권 불편 리뷰는 37건으로 표본이 작아 3사 비교로 읽어 주세요."

## 화면 3. 객단가를 올릴 기회 — 커머스 방식으로 읽기

시트 이름: `3 기회` / 원본: `t3_opportunities`

| 항목 | 설정 |
|---|---|
| 행 | `commerce_lever` — 정렬: `SUM(pain_reviews_3co)` 내림차순 |
| 열 | `SUM(pain_reviews_3co)` — 축 제목 "3사 불편 리뷰(건)" |
| 마크 | 막대 |
| 색상 | `SUM(share_3co)` (회색 → 주황) |
| 레이블 | `SUM(share_3co)` 백분율 서식(소수 0자리) |
| 세부 정보 | `journey_stage`, `meaning`, `top_pain_type`, `example_requests`, `pain_reviews_kis` |
| 도구 설명 | **`<commerce_lever>`** (`<journey_stage>`) / `<meaning>` / 가장 많은 불편: `<top_pain_type>` / 고객 요청 예: `<example_requests>` / 한국투자증권 `<SUM(pain_reviews_kis)>`건 |

주석: **"마이페이지·재방문 37%, 상품 큐레이션 29% — 계좌가 커지는 게 보이지 않고, 넣은 돈을 굴릴 상품을 고르기 어렵다"**

## 대시보드 조립

새 대시보드 `IRP 객단가 레이더`, 크기 고정 1200 × 1000.

```
┌───────────────────────────────────────────────────────────────┐
│ 제목: IRP 객단가 레이더                                         │
│ 부제: 한국투자증권은 IRP 계약 수 1위, 계약 1건당 적립금은 미래에셋의 42% │
├──────────────────────────────┬────────────────────────────────┤
│ 1 객단가 격차 (산점도)          │ 2 불편 히트맵 (+ 회사 필터)       │
├──────────────────────────────┼────────────────────────────────┤
│ 3 기회 (막대)                  │ 4 관리 (텍스트 표)               │
├──────────────────────────────┴────────────────────────────────┤
│ 출처: 금융감독원 통합연금포털 연금통계(2025년 말), 구글 플레이 공개 리뷰 │
│ 리뷰 원문은 공개하지 않습니다. 투자 권유가 아닌 서비스 기획 분석입니다.  │
└───────────────────────────────────────────────────────────────┘
```

- 바둑판식(타일)으로 배치하고 각 시트 제목은 표시합니다.
- 화면 2의 `company` 필터를 대시보드 오른쪽 위에 둡니다.
- 동작(선택): 화면 3 막대를 클릭하면 화면 2가 해당 `journey_stage`로 필터되도록 **대시보드 > 동작 > 필터 추가**. 두 원본의 `journey_stage` 필드를 대상 필드로 매핑합니다.

## Tableau Public에 저장

1. **서버 > Tableau Public > Tableau Public에 저장**을 누르고 본인 계정으로 로그인합니다(계정은 직접 만들어야 합니다).
2. 통합문서 이름: `IRP 객단가 레이더`
3. 저장 후 Tableau Public 페이지의 설정에서 **"다른 사람이 통합문서를 다운로드하도록 허용"은 꺼 둡니다.** 올린 데이터는 집계값뿐이지만 공개 범위를 최소로 유지합니다.
4. 공개 링크를 README의 `## 대시보드` 절에 붙입니다.
